TN Channel

Regional TV · Hybrid Linear-OTT Model

A free, ad-supported hybrid TV model for Tamil Nadu — users pick content like OTT via WhatsApp, but it plays linearly, with zero broadband dependency.

The 4-movie grid →
Context
The Market Gap
15M+ cable/DTH households in Tamil Nadu want control over content but can't afford or access OTT (Rs.199–499/month + broadband). TN Channel bridges linear TV's simplicity with OTT's sense of choice — completely free.
Market Context
01
4-Movie Daily Grid via WhatsApp
Users select from a 4-movie daily grid via WhatsApp or app. The system maps their Set-Top Box ID — at slot time, their TV automatically routes to the selected movie, playing linearly.
Core Concept
02
4x Ad Arbitrage
Four parallel feeds mean 4x the ad inventory of a traditional linear channel — a locked, no-pause viewing experience drives ad completion rates far above typical linear TV.
Monetisation
03
Works on Dumb Set-Top Boxes
No smart TV or software upgrade required — the backend does all the routing work over existing copper cable and DTH infrastructure already in 15M+ homes.
